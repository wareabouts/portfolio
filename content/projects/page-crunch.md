This was made as the final project for WEB. We had to make a game with what we'd learned about HTML, CSS & Javascript. I'd been interested in using unique controls and decided users would play the game by resizing the browser window. The green cube is attached to the bottom left of the screen, and the goal is fixed to the top left. The user has to resize the browser, avoiding the white square obstacles and reach the purple goal.
